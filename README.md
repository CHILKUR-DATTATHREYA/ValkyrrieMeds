## 🔒 Security Architecture

<div align="center">

| 🛡️ Security Layer | 🔧 Implementation | ✅ Coverage |
|---|---|---|
| 🔐 Password Hashing | bcryptjs with salt rounds | All local account credentials |
| 👤 User Store | Persistent JSON store (excluded from repo) | Account persistence between sessions |
| 🚫 Unregistered Block | Server-side credential verification + "Not Registered" modal | Prevents phantom login |
| 🔑 OAuth | Google OAuth 2.0 + LinkedIn OAuth 2.0 | Secure social login / registration |
| 🙈 Git Secrets | Strict .gitignore — no .env, no user data, no secrets pushed | Repository-level protection |
| ⚖️ Legal | Proprietary Commercial License | IP + brand asset protection |

## 💻 Local Development Setup

```bash
# 1. Clone the repository (authorized personnel only)
git clone https://github.com/CHILKUR-DATTATHREYA/ValkyrrieMeds.git

# 2. Navigate to project directory
cd ValkyrrieMeds

# 3. Install dependencies
npm install

# 4. Configure environment variables
cp .env.example .env.local
# Fill in your OAuth credentials, email config, and secret keys

# 5. Start development server
npm run dev
```

> Open [http://localhost:3000](http://localhost:3000) to view the portal locally.
