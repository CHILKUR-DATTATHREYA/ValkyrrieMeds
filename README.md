## 🌟 About Valkyrrie Meds

**Valkyrrie Meds Pvt. Ltd.** is a transformative platform dedicated to holistic human potential, leadership development, and emotional wellness.

### The Three Foundational Pillars:
1. **Entrepreneurship & Startup Development**: Practical business modeling, market opportunity validation, financial literacy, and founder mentorship.
2. **Soft Skills for Life & Leadership**: Executive public speaking, persuasive communication, conflict resolution, and high-trust teamwork.
3. **Healing Through Meditation**: Guided mindfulness, nervous-system equilibrium, stress reduction, and emotional composure under pressure.

---

## 🚀 Technical Architecture

- **Framework**: Next.js 16 (App Router with Turbopack)
- **Styling**: Tailored Design System with vanilla CSS variables and smooth transitions
- **Typography**: Plus Jakarta Sans & Inter
- **Authentication**: Rigorous credential verification with bcryptjs hashing, persistent store, and OAuth integration
- **Email Engine**: Dual-dispatch executive HTML notifications routing to `valkyrriemeds@gmail.com` and confirmation receipts to clients

## 💻 Local Setup & Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run production build
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the portal locally.
